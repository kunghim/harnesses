# harnesses

面向用户、开发者和 Agent 的开放 AI Harness 资料库。项目目标是收录所有身份可核验的 AI Harness，覆盖 CLI、桌面、IDE 扩展、云端与自托管产品。

资料包括产品与厂商、官方入口与下载、版本和平台、检测与配置路径、扩展、调用和会话。档案中的规则记录适用条件和来源。网页、整库 JSON、HTTP API 与远程 MCP 使用同一份发布快照。

项目处于技术设计阶段。计划站点为 harnesses.top。
